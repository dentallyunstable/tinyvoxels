# tinyvoxels
Voxel Builder App, simple and optimized.

A 3D voxel building/editing app with a simple UI which works well on low-end phones.

## Properties
- Ability to add/delete voxels.
- Ability to paint voxels.
- Ability to undo/redo actions.
- Ability to rotate and zoom in/out 3D object.
- Ability to freely move in the 3D dimension.
- Ability to get an isometric view of the object.
- Save the object as .vox.
