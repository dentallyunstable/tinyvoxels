# tinyvoxels
Voxel Builder App, simple and optimized.

A 3D voxel building/editing app with a simple UI which works well on low-end phones.

## Properties
- Ability to add/delete voxels.
- Ability to paint voxels.
- Ability to undo/redo actions.
- Ability to rotate and zoom in/out 3D object.
- Ability to freely move in the 3D dimension.
- Ability to get an isometric view of the object.
- Save the object as .vox.
## How to use
Open `index.html` in any modern browser (phone or computer). It's a single file with no installation and no internet needed.

- **Tools:** Add, Delete, Paint, Pick (copies a cube's color). Tap or click a cube to use the selected tool.
- **Phone:** one-finger drag rotates, pinch zooms, two-finger drag moves the view.
- **Computer:** drag rotates, right-drag or Shift-drag moves, scroll zooms, `W A S D` / `Q E` fly around, `Ctrl+Z` / `Ctrl+Y` undo/redo, `1`–`4` pick tools, `I` isometric view, `F` center view.
- **Menu:** choose the build space size (8, 16, 32, 64 or 128 cubes per side), save or open `.vox` files (MagicaVoxel format), or start fresh.
- Your work is saved automatically in the browser on that device.
